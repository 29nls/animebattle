# Perbaikan rendering teks bergradien

Tanggal: 2026-11-08

Ruang lingkup: `.text-gradient-hero` dan `.text-gradient-vs`, plus test regresi CSS.

Status: selesai dan terverifikasi di peramban.

## Akar masalah

CSS hasil build memecah gradien `oklch` menjadi dua aturan: fallback warna hex dan aturan modern di dalam `@supports (color: lab(...))`. Aturan modern hanya menulis shorthand `background`, sehingga properti itu mereset `background-clip` dari `text` kembali ke `border-box` pada elemen dengan specificity yang sama.

Akibatnya, background gradien menutupi seluruh kotak teks. Teks tetap transparan karena `-webkit-text-fill-color: transparent`, jadi yang terlihat adalah blok warna.

Bukti sebelum perbaikan:

- `.text-gradient-vs` memiliki dua aturan di CSS build.
- Aturan `@supports` hanya menulis `background`.
- Computed style: `background-clip: border-box`.
- Judul "Pertarungan" dan badge VS tampil sebagai blok warna.

## Perbaikan

Kedua kelas memakai `background-image`, bukan shorthand `background`:

- `.text-gradient-hero`
- `.text-gradient-vs`

`background-image` tidak mereset `background-clip`, sehingga aturan fallback di dalam `@supports` tidak lagi menghapus efek potongan teks. Tidak ada perubahan warna, ukuran, atau tata letak.

CSS hasil build sekarang:

- `.text-gradient-hero`: `background-image` pada fallback dan aturan modern, diikuti `background-clip: text`.
- `.text-gradient-vs`: `background-image` pada fallback dan aturan modern, diikuti `background-clip: text`.
