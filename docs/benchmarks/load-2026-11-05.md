# Load test k6 — 2026-11-05

Hasil ini adalah **pengukuran lokal**, bukan prediksi produksi. Semua angka di
bawah diambil dari `--summary-export` k6 yang ditulis oleh
`scripts/run-loadtest.sh`, bukan dari perkiraan.

## Lingkungan

| Komponen | Nilai |
|---|---|
| Mesin | Windows, Git Bash; aplikasi dan database di mesin yang sama |
| Node.js | v26.13.0 |
| k6 | v2.3.0 (`k6-v2.3.0-windows-amd64`) |
| Aplikasi | `next build` + `next start` (build produksi) |
| Database | `embedded-postgres` 16.15.0-beta.19 — Postgres asli, proses lokal |
| Dataset | One-Punch Man lewat `applyDataset` produksi: 60 record, 73 baris dibuat (3 karakter, 3 form) |
| Jaringan | loopback; tanpa CDN, TLS, atau connection pool Supabase |

## Skenario dan ambang

Ambang didefinisikan di `tests/load/*.js` dan ditegakkan k6 (exit non-zero bila
dilanggar):

| Skenario | VU | Durasi | Ambang |
|---|---:|---:|---|
| `/api/search?q=...` | 3 | 20 s | error < 1%, p95 < 500 ms |
| `/api/battle/simulate` | 3 | 20 s | error < 1%, p95 < 1000 ms |
| `/versus/[a]-vs-[b]` | 5 | 20 s | error < 1%, p95 < 1000 ms |

## Hasil

| Skenario | Permintaan | p50 | p90 | p95 | maks | Error |
|---|---:|---:|---:|---:|---:|---:|
| Search | 72 | 16,25 ms | 29,24 ms | **34,51 ms** | 437,73 ms | **0%** |
| Battle simulate | 60 | 27,26 ms | 40,41 ms | **52,28 ms** | 149,01 ms | **0%** |
| Versus | 91 | 43,36 ms | 120,61 ms | **693,34 ms** | 1.255,71 ms | **0%** |

Ketiga ambang lulus dan seluruh rangkaian keluar dengan `LOADTEST_EXIT=0`.
Versus punya ekor paling panjang (p50 43 ms vs p95 693 ms) karena setiap
permintaan merender halaman React server-side dan memuat data pertarungan,
bukan sekadar query.

## Batas representativitas

1. **Bukan katalog 200 karakter.** Dataset hanya 3 karakter; target "200
   karakter siap-battle" tidak diuji dan tidak dibuktikan oleh angka ini.
2. **Bukan p95 produksi.** Database berjalan di mesin yang sama tanpa jaringan;
   Supabase/Vercel menambah RTT dan batas connection pool. Angka lokal tidak
   boleh dikutip sebagai p95 produksi.
3. **Bukan uji ketahanan.** 3–5 VU selama 20 detik mengukur latensi dasar, bukan
   spike, soak, atau batas laju rate limiter.
4. **Tidak menguji autentikasi.** Ketiga rute bersifat anonim; rute admin/cron
   tidak termasuk.
5. **Satu run per skenario.** Varians antar-run tidak diukur.

## Cara mengulang

```bash
npm run build
bash scripts/run-loadtest.sh
```

`scripts/loadtest-db.mjs` menulis `.loadtest-env.json` (gitignored); hasil mentah
`.loadtest-{search,battle,versus}.json` juga gitignored. Jangan commit keduanya.
